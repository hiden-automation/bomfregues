Dúvidas Frequentes

Perguntas comuns

Tudo o que você precisa saber sobre como funciona o app no dia a dia do seu comércio.

O cliente precisa baixar o app pela App Store ou Google Play? +
Não! O Bom Freguês é um PWA (Progressive Web App). O cliente só aponta a câmera para o QR Code do balcão e adiciona o app à tela inicial com apenas um toque, sem ocupar espaço no celular nem exigir senhas de lojas de aplicativo.
Como o leitor de cupom evita fraudes de clientes? +
O leitor possui proteção anti-fraude integrada: o sistema valida se a compra pertence ao seu comércio e impede automaticamente que o mesmo cupom fiscal seja registrado mais de uma vez.
Como funcionam as notificações push? +
Quando o cliente autoriza os avisos no app dele, ele fica inscrito exclusivamente para a sua loja. Pelo seu painel administrativo, ao publicar uma nova promoção, o sistema envia uma notificação na tela de bloqueio com o título, descrição e foto do produto apenas para os seus clientes.
Se o cliente trocar de celular, ele perde os pontos? +
Não. O cliente pode vincular o CPF dele ao saldo com facilidade a qualquer momento. Ao abrir o app em outro aparelho e digitar o mesmo CPF, o saldo anterior é resgatado automaticamente.
